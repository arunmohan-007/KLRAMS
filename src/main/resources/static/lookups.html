Lookup & Short Code

Pick a layer, pick one of its attributes, and set the values that attribute may hold — each with the short code the survey returns use for it. A lookup only takes effect once the attribute’s data type is Lookup, which the switch below sets. Once on, those values are the only ones the attribute accepts, by code or in full, and they are what every map card and report shows.
