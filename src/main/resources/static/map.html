Heat Map Analysis
Build a kernel density surface from a point dataset. The result is derived on each run from the choices below — it is an analysis, not a stored layer, so it is rebuilt every time and cleared explicitly.
1 · Dataset
2 · Heat value
3 · Boundary layer
Drawn over the surface as a reference frame. It does not clip the heat — a density surface is continuous and legitimately crosses a district border.
4 · Kernel
The surface is drawn under the point layers, so switch the dataset’s own layer on to check the heat against its inputs. When a Road Network filter is applied, only the points it matches are analysed. Traffic runs apply the station-group correction from Calculation Rules: the two carriageways of one physical count station are a single heat point carrying both directions’ traffic.

Pavement Condition Index

PCI — IRC:82-2023

Set the six distress weightages and generate the index. The map is hidden while you work here.
PCI = Σ ( wi × Ii ) · six indices · 0–100 scale
Weightage factor (editable)Σ weights = 1.00
PCI rating scale (Table 5.5)
Generate PCI produces two layers — Composite PCI (area-weighted distress) and Worst-Lane PCI (maximum distress per parameter). Each parameter’s distress is converted to a 0–100 index; thresholds follow IRC:82-2023 Table 5.3 (editable under Road Condition). Default weightages are IRC:82-2023 Table 5.4 (Σ = 1.00).
