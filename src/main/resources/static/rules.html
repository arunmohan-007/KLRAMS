Calculation Rules

The corrections and constants behind every published figure — which road sections are one dual carriageway, which count rows are one traffic station, the metres behind a pavement width band, and the IRC:82‑2023 PCI weights. Each rule shows what the figure was before the correction and after it, and where in KLRAMS it is used. These were fixed rules inside the code until now; they were seeded with exactly what the code was already producing, so nothing moved when this screen arrived.
