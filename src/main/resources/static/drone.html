Drone

Drone survey projects and their imagery. Each project is one flight over a stretch of road and holds up to two rasters — an orthomosaic and a DEM. Uploading reads the coordinate system, extent and resolution straight out of the GeoTIFF; publishing turns it into map tiles so it can be drawn over the KLRAMS road network without the browser ever downloading the full image.

GeoTIFF only (.tif / .tiff), with the coordinate system embedded — WGS 84 geographic (EPSG:4326) or WGS 84 / UTM zone 43N (EPSG:32643), which is what drone software produces for Kerala. The original file is kept exactly as uploaded; the map tiles are built from it separately.
